## Plan: Hoàn thiện tính năng Thông báo (Telegram + in-app) cho ShipLedger

**Bối cảnh:** Backend notification đã có sẵn trong working tree (schema `notifications`+`settings`, migration `0001_notifications.sql`, `lib/telegram.ts`, `lib/notifications.ts`, server actions, hook trong `invoices.ts`, component `notifications-list.tsx` + `settings-manager.tsx`). Người dùng chọn **chỉ Telegram**, plan tập trung **hoàn thiện phần còn thiếu**: 3 trang UI, nav entry, badge chưa đọc, và chạy migration.

### 1. Tạo 3 trang còn thiếu (theo pattern server-component + client-component hiện có)

- **`app/admin/notifications/page.tsx`** — server component gọi `getMyNotifications()`, render `<NotificationsList title="Thông báo" description="..." notifications={...} />`
- **`app/driver/notifications/page.tsx`** — tương tự, cho driver
- **`app/admin/settings/page.tsx`** — server component gọi `getSettings()`, render `<SettingsManager initialConfig={...} />` (cấu hình Telegram: bật/tắt, bot token che dấu, chat ids, nút "Gửi tin nhắn thử")

### 2. Cập nhật navigation + badge chưa đọc

- **`components/dashboard-shell.tsx`**: type `NavItem` thêm `badge?: number`; render badge nhỏ (số) cạnh label khi `badge > 0` — cả desktop và mobile nav
- **`app/admin/layout.tsx`**: thêm nav `Thông báo` (`/admin/notifications`, kèm badge từ `getUnreadCount()`) và `Cài đặt` (`/admin/settings`)
- **`app/driver/layout.tsx`**: thêm nav `Thông báo` (`/driver/notifications`, kèm badge từ `getUnreadCount()`)

Badge tự cập nhật sau khi đánh dấu đã đọc nhờ `revalidatePath` đã có sẵn trong actions + `router.refresh()` trong component.

### 3. Chạy migration lên database

- Chạy `lib/db/migrations/0001_notifications.sql` (idempotent `CREATE TABLE IF NOT EXISTS`) lên DB qua `DATABASE_URL` trong `.env.local` (dùng node + `pg`, không in secrets). Nếu không kết nối được DB → báo lại, đưa lệnh psql để người dùng tự chạy.

### 4. Kiểm tra

- `pnpm lint` + `pnpm build` sạch
- Xác minh luồng: driver gửi hóa đơn → `notifyNewInvoice` tạo thông báo cho tất cả admin + driver, gửi Telegram qua `after()` (nếu đã cấu hình token/chat id trong settings)

### File thay đổi

**Mới (3):** `app/admin/notifications/page.tsx`, `app/driver/notifications/page.tsx`, `app/admin/settings/page.tsx`
**Sửa (3):** `components/dashboard-shell.tsx`, `app/admin/layout.tsx`, `app/driver/layout.tsx`

Không đụng tới backend đã hoạt động (lib/actions/schema/migration đã đầy đủ).
