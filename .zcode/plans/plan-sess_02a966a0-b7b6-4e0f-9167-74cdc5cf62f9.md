## Plan: Tính năng đổi mật khẩu cho driver & admin

### Cách làm
Dùng **API có sẵn của better-auth** (`/change-password` — project đã dùng better-auth cho auth) gọi **phía server** qua server action, kèm `revokeOtherSessions: true` để đăng xuất các thiết bị khác sau khi đổi (bảo mật chuẩn, phiên hiện tại vẫn giữ nguyên).

### 1. Server action — `app/actions/auth.ts` (thêm `changeMyPassword`)

- `requireUser()` để chặn chưa đăng nhập
- Validate phía server: mật khẩu mới ≥ 8 ký tự (khớp rule tạo tài xế hiện có), 2 field bắt buộc
- Gọi `auth.api.changePassword({ body: { currentPassword, newPassword, revokeOtherSessions: true }, headers })` (`headers` từ `next/headers`, đúng pattern `lib/session.ts`)
- Bắt lỗi API → map sang tiếng Việt:
  - `INVALID_PASSWORD` → "Mật khẩu hiện tại không đúng"
  - `PASSWORD_TOO_SHORT` → "Mật khẩu mới phải có ít nhất 8 ký tự"
  - `CREDENTIAL_ACCOUNT_NOT_FOUND` → "Tài khoản này không dùng mật khẩu đăng nhập"
- Trả `{ success: true }` hoặc `{ error: string }` (đúng pattern actions hiện có)

### 2. Component dùng chung — `components/change-password-form.tsx` (mới)

Client component, theo đúng phong cách `auth-form.tsx`/`settings-manager.tsx`:
- 3 field: mật khẩu hiện tại, mật khẩu mới, xác nhận mật khẩu mới (dùng `Input type="password"`)
- Validate client: mật khẩu mới ≥ 8 ký tự, xác nhận khớp
- Submit qua `useTransition` + server action, hiển thị lỗi inline (`text-destructive`) / thành công ("Đã đổi mật khẩu")
- Sau khi thành công: reset form, `router.refresh()`

### 3. UI cho từng vai trò

- **Admin**: thêm section "Đổi mật khẩu" ngay trên trang `/admin/settings` hiện có (render `<ChangePasswordForm />` bên dưới card cấu hình Telegram) — không cần page/nav mới
- **Driver**: tạo trang mới `app/driver/settings/page.tsx` (server component đơn giản, render `<ChangePasswordForm />` kèm tiêu đề) + thêm nav "Đổi mật khẩu" (`/driver/settings`) vào `app/driver/layout.tsx` (sẽ nằm trong hamburger menu trên mobile — hợp lý)

### 4. Kiểm chứng

- `npx tsc --noEmit` + `pnpm build` sạch
- Thủ công: đổi mật khẩu thành công → đăng xuất → đăng nhập bằng mật khẩu mới OK; nhập sai mật khẩu cũ → lỗi inline đúng; mật khẩu mới < 8 ký tự → bị chặn; thiết bị khác (session khác) bị đăng xuất sau khi đổi
